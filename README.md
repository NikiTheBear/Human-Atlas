# 人性全息图谱 · The Human Atlas

> 分卷潜行式多维深度测评系统 · 纯前端 · 零后端 · 零第三方图表库

**双季十六卷**：第一辑 · 本源八卷（152 题 / 60 维）+ 第二辑 · 破圈深水八卷（146 题 / 67 维），共 **298 个情境题、127 个可追踪维度**。

任意一卷即可独立作答并生成报告；完成 ≥3 卷触发跨卷交叉读心（65 条黄金规则）；完成 ≥5 卷激活面具显影；完成核心八卷解锁 36 种复合原型与《个人人性全息白皮书》。

## 两个入口，别搞混

| 文件 | 用途 | 怎么打开 | 外部依赖 |
| --- | --- | --- | --- |
| **`human-atlas.html`** | **发给别人 / 自己用** | 双击即可 | 无（全部内联） |
| `index.html` | 开发时用（改源码即时生效） | 必须 `npm start` 或双击 `启动.command` | 引用 `src/` `styles/` |

`index.html` 用的是 `<script type="module" src="src/main.js">`。Chrome / Safari 在
`file://` 协议下会拦截 ES module，页面会永久停在「正在开启档案馆」——
**这不是加载慢，是脚本根本没执行**。所以：

- 想直接双击 → 用 `human-atlas.html`
- 想改代码 / 即时预览 → 用 `index.html` + 本地服务

### 发给朋友

只发 **`human-atlas.html`** 这一个文件（522 KB）。微信 / 邮件 / AirDrop 都行。
对方双击就能用，进度存在他自己浏览器里，与你无关。

如果对方也想看到他朋友们的对比，他可以把报告页生成的 `HA4-` 存档码发回来。

## 核心算法

### 维度标准分

```
S_d = 50 + 50 · Σ(w_i · centered_i) / Σ w_i
```

- `centered_i ∈ [-1, 1]`：该题在维度 d 上的作答相对该题可能区间的中心化位置
- `w_i`：题型权重（迫选 1.4 / 直觉 1.2 / 筹码 1.3 / 量表 0.85）
- 盲选（长题干 < 1200ms）权重 × 0.4

### 社会面具厚度 M

```
M = min(100, 0.35·D_sd + 0.25·H_lat + 0.40·G_mirror)
```

- `D_sd`：社会期许偏移率（落在高赞许端的标准化比例）
- `H_lat`：敏感题犹豫修饰度（耗时 > 2.2× 期望 或 改选 ≥ 2 次且最终选高赞许项）
- `G_mirror`：跨卷镜像撕裂度（同一 `mirror_key` 下明线 vs 暗线分数差，以 45 分为满量程）
- 未完成 Vol.8 时 `G_mirror` 不参与，前两项自适应重归一化

### 双人契合度

```
overall = 0.58 · R_sync + 0.42 · R_complement − Σ 碰撞罚分
```

- `R_sync`：三观 + 光明/黑暗维度的平均绝对差（100 − 平均差）
- `R_complement`：大五 + 思维的差异曲线，20–45 分为"黄金互补区"得分最高
- 碰撞罚分：high 5.5 / mid 2.5，上限 20（冲突是关系的一部分，不归零）

Base64url 编码的紧凑字节串，包含：版本、已完成卷掩码、面具厚度、Top3 价值索引、
60 个维度分数（取整）、昵称与校验和。**不含任何答案原文**。

典型长度约 106 字符，可直接粘贴到微信/备忘录，在另一台设备恢复进度或用于双人对比。

### Phase 1 · 极速模式

`src/data/express.json` 只存 28 个题目 id 引用，不复制题干。作答写入虚拟桶
`answersByVolume.__express`，收卷时 `commitExpress()` 按来源卷写回真实卷 ——
**极速版答过的题，进完整卷时自动显示已答；完整卷答过的题，进极速版时自动跳过。**

不写 `completedVolumes`，所以不会误触发「完成 3 卷」这类跨卷门槛。

### Phase 2 · 六大关系生态位

`src/core/ecology.js` 用 6 套权重矩阵，每个维度带一个 `kind`：

| kind | 含义 | 门控 |
| --- | --- | --- |
| `syncHigh` | 相似且双方都在高位 | `(min − 35) / 30`，中性组合落在 50 |
| `syncLow` | 相似且双方都在低位 | `(65 − max) / 30` |
| `sync` | 纯相似 | — |
| `tension` | 差异落在 20–45 最好 | 分段曲线 |
| `bothHigh` | 双方都高才得分 | — |

初版只用 `100 − |a − b|`，两个完全一样的人会拿满分，六个生态位**全是 100**。
加上水平门之后中性组合落在 50 附近，真有共同底色才上得去：

```
全中性      → 日常合住 63.6
双高暗黑    → 镜面宿敌 74.7
互补工作    → 事业搭档 70.2
精神同频    → 灵魂知己 87.7
一起不在乎  → 灵魂知己掉到 31.5   ← 水平门生效
```

配三个模块：关系三幕剧（追逃 / 双回避 / 硬碰硬 / 单侧让步四类摩擦）、
潜台词解码器（10 条规则取前 3）、相处红黑榜（从欲望引擎 / 图式 / 道德基础提炼）。

### Phase 3 · 个人实验室

**压力变形沙盒** —— 一套可解释的线性偏移模型：

```
energy 0（耗竭）→ 暗面维度 +16，明面维度 −16
energy 50（常态）→ 原样
energy 100（充沛）→ 反过来
```

「暗面」不是随意的，由维度自身极性决定（原罪 / 暗黑三角 / 防御 / 图式越耗竭越强）。

**内在议会** —— 16 组高张力维度对（自由×安全、高敏×求新、高自尊×依恋焦虑…），

另加两项：

- **证据收缩**：只被 1–2 道题测到的维度会向 50 分拉，避免「答对一次就是满分」。
- **个人 Z 尖峰**：`Z_d = (S_d − μ) / max(σ, 6)`，用于打破「所有人都挤在 45–60」的中庸魔咒。王牌天赋卡与阴影预警卡综合绝对分与 `|Z|` 排序。

### 遥测清洗

`telemetry.js` 新增 `createFocusTimer()`：监听 `visibilitychange` / `blur`，把切屏与失焦时长从净耗时里扣除。单题净耗时 > 25s 自动标记 `dirty`，剔出阅读基线与犹豫分计算。

### 构建期校验

`npm run data` 现在会做三件事，任一失败即 `exit 1`：

1. **野字段扫描** —— 任何 `effects` 键必须属于 `dimensions.json` 注册表。
2. **去 AI 腔黑名单** —— 题库里不得出现 `林舟/沈明/陆言/把牌摊开/把桥烧掉` 等词。
3. **维度覆盖率** —— 60 维双面镜必须齐全。

## 万次蒙特卡洛审计

```bash
npm run test:monte        # 2,000 轮（约 15 秒，日常用）
npm run test:monte:full   # 10,000 轮（约 100 秒，发版前用）
npm run test:all          # 151 项 + 2,000 轮审计
```

`tests/monte-carlo-audit.js` 不是随机撒点，而是给每个仿真体一个**潜在特质向量**，作答时按特质投票——纯均匀随机会把所有维度压到 50，测不出分布问题。

三类画像混跑：

| 画像 | 用途 |
| --- | --- |
| 随机人格（潜在特质 + 噪声） | 检验分布宽度与均值偏移 |
| 极端伪装者（全选最高赞许 + 优先选「用理性解释自己」+ 敏感题超长犹豫） | 点亮 `mask` 类规则 |
| 双面者（明线选最体面 / 暗线选最不体面） | 把 `G_mirror` 拉到最大值 |

审计八项：

1. **野字段** —— 127 维之外的任何 `effects` 键
2. **死维** —— 从未产出分数的维度
3. **分布过窄** —— `sd < 4`，说明该维度几乎测不出个体差异
4. **均值偏移** —— `μ < 32` 或 `μ > 68`，说明存在系统性打分偏差
5. **过度贴边** —— 低端或高端占比 >35%
6. **死规则** —— 从未被触发的跨卷规则
7. **原型覆盖** —— 36 种原型是否有永远选不中的
8. **存档码往返** —— 万次编解码无失败

当前 10,000 轮：**10/10 全通过**（127 维 × 10,000 次，71 秒）。

这一轮抓到两个真 bug：

- **计分居中偏差**：`covert_control` 只出现在部分选项里，旧算法（区间中位数为中心）把它均值压到 32 分。改成期望值居中后回到 48.6。
- **原型反向权重失效**：`AR16 深海稳压器` 里 `big5_rumination: -1.4` 表示「越低越像」，但代码写的是 `acc += s * w`，理想画像只拿到 25.7 分、永远选不中。改成按极性取 `100 − s` 后达到 80.5，36 种原型全部可命中。

## 设计原则

1. **零说教**：选项里没有"我很自私"这类直白标签，只有高级合理化后的真实处境。
2. **双面镜**：任何维度的高分与低分都不判优劣，各自拆成"优势面"与"阴影面"。
3. **分卷即闭环**：不需要先熬完 298 题才能看到有价值的东西。
4. **数据即代码**：题库、文案、规则全部可独立编辑，UI 不硬编码任何内容。
5. **纯本地**：不上传、不埋点、不需要账号。所有计算在你的浏览器里完成。
