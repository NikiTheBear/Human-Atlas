# 人性全息图谱

十六卷、298 道情境题、127 个维度。纯前端，没有服务器，没有账号，不联网。

**[直接打开](https://nikithebear.github.io/Human-Atlas/)** · **[下载离线版](https://github.com/NikiTheBear/Human-Atlas/releases/latest)**

---

## 先说清楚这是什么，不是什么

它是一套结构化的自我描述工具。你把 298 道题答完，它给你 127 个维度的分数，再把这些分数拼成模式——你身上哪几股力量在互相拉扯，你累的时候往哪个方向塌，你和另一个人在什么位置上合得来。

它不是心理诊断，不构成医疗建议，也替代不了找个人好好聊一次。做这个的初衷是让「描述自己」这件事有个可操作的语言，不是让谁拿着报告去给自己或别人下结论。

---

## 用起来是什么感觉

不分卷，但也不逼你一次做完。**做完任意一卷就能看那一卷的报告**，不用先熬 298 题。做完三卷才会有跨卷的东西出现，五卷解锁面具，八卷是完整档案。

题型混着来，因为一直点「非常同意 / 比较同意」谁都会烦：

- 四选一的情境题——给你一个具体场景，选你最可能的反应
- 七点量表，但没有数字，圆点从大到小排，靠手感选
- 3 秒直觉脉冲题，高亮倒计时窗口内捕捉第一反应，已选即锁定防反复润色（仅可显式解锁改选并记入摇摆校准）
- 把 100 点分配到几个选项上，逼你做取舍
- 从八张卡里挑三张排顺序

有些题的选项读起来都不太体面。那是故意的：真实处境里，人往往在两个都不太好的选项之间选。

## 报告里有什么

**双面镜** —— 127 个维度每个都写了明暗两面。同样是「高标准」，一面是专业骨气，另一面是永远不满意。它不告诉你哪个是「对的」，只把两面都摆出来。

**面具厚度** —— 一个 0 到 100 的数，由三样东西合成：你多倾向于选社会赞许的答案、你在敏感题上犹豫了多久、你在明线题和暗线题上给出的答案差多少。最后一项最准，因为它比的是你嘴上说的和你下意识选的。

**36 个原型** —— 带覆盖率闸门。你的维度测得不够多的时候它会说「还不足以判定」，而不是硬塞给你一个最像的。

**65 条跨卷规则** —— 比如「高马基雅维利 × 高康德式正直」会给出「你既相信原则，又清楚规则怎么运作，所以常在心里给自己记账」这类描述。规则只在完成三卷后才跑。

## 双人和多人

两个人各答一卷，把存档码贴到对比页，会得到七个关系生态位各自的分数：

**长期伴侣 / 心动拉扯 / 灵魂知己 / 事业搭档 / 日常合住 / 镜面宿敌 / 同行挚友**

七个用的权重矩阵完全不同。长期伴侣要三观底线都在高位且接近；心动拉扯恰恰需要差异，两个人太像反而没火花；同行挚友不需要世界观一致，只要节奏合、边界干净。

分数下面会展开逐条维度的对照，能看见你们在哪条轴上差了多少、这条轴在这个关系里算加分还是减分。

除此之外还有：关系三幕剧（按双方防御结构推演第一次摩擦会长什么样，不是预言）、潜台词解码器（十种会说反话的防御，取对方最强的三条）、相处红黑榜。

**三人以上**可以用群像星图，会分六种小队角色、算缘分矩阵、找共同短板。

## 几个小工具

**压力沙盒** —— 一根电量滑杆拖到 0，看你 127 个维度怎么变形。暗面维度（原罪、暗黑三角、防御）会涨，明面维度会跌，荣格八维这类结构性认知基本不动。拖完松手，原始分数一个字节都不会变。

**内在议会** —— 找出你身上张力最高的三对维度，写成双声部对话。比如「高自尊」和「依恋焦虑」同时高，就是「我不需要向谁证明什么」和「TA 一冷淡我就怀疑自己」这两句话在打架。

**印象盲盒** —— 生成一条邀请链接，朋友不用测自己，只凭直觉答 12 道关于你的题，之后会看到乔哈里窗四象限：你们都知道的、只有 TA 看见的、只有你知道的、谁都没触及的。

## 数据在哪

全在你自己浏览器的 localStorage 里。没有后端，没有任何网络请求。

想跨设备，就导出存档码：

- `HA4-` 开头，约 187 个字符，装 16 卷完成状态 + 127 维分数 + 面具 + 昵称。**不含任何答题原文。**
- `HA4J-` 开头，24 到 72 字符，是印象盲盒的邀请码
- 也支持导入 `.json` 完整备份，那个会含逐题作答

导入时的行为：以你本地已有的分为底盘，导入的分只在本地没有的维度上补。所以不会覆盖你已经做过的题。

## 一些实现上的取舍

**为什么纯前端**。心理测评这类东西，数据一旦上云，性质就变了。所以宁可放弃跨设备便利，也不要一个账号系统。

**为什么不做成 PWA**。会做，但优先级排在内容准确后面。

**为什么维度这么多**。127 个是因为要覆盖足够多的理论框架（大五、暗黑三角、依恋、荣格八维、九型、图式、道德基础、时间观……），不是为了数字好看。代价是报告很长，所以我把它折叠了几块——默认只展开你最先要看的那几个。

**为什么分数不是百分制**。50 是中性，因为受了贝叶斯收缩。只被一两道题测到的维度会被拉回 50 附近，免得「答对一次就满分」。想看相对强度，看 Z 分（个人内部尖峰）更准。

## 本地跑

```bash
npm start          # http://localhost:4173
npm test           # 301 项验收
npm run test:render    # 真浏览器验 DOM（21 条）
npm run build      # 生成 dist/ 和单文件版
```

`human-atlas.html` 和 `src/data/bundle*.js` 是构建产物，不入库。首次 clone 跑一次 `npm run build`，或者直接 `npm test`，`pre*` 钩子会自动生成。

想改题库，改 `src/data/volumes/*.json`，然后 `npm run data` 重新编译。改完记得跑 `npm test`，里面有数据契约的断言（题量、维度覆盖、选项字数比、id 唯一性）。

## 目录上哪找东西

```
src/core/       算分、存档码、报告拼装、关系算法、实验室
src/components/ 各个页面
src/viz/        原生 SVG 图表，没有第三方图表库
src/data/       题库、双面镜、原型、规则——全是可编辑的 JSON
tests/          Node 层验收 + 浏览器渲染冒烟
local-studio/   本地深度解读工作台（不上线，见下）
```

想只读代码的话，建议顺序：`src/core/scoring.js` 看分数怎么来的 → `src/core/synthesizer.js` 看报告怎么拼 → `src/core/ecology.js` 看关系怎么算。

## 本地深度解读工作台

`local-studio/` 是我自己用的一套东西，不上线也不在仓库里（在 `.gitignore` 内）。它做的是一件事：把上面那堆分数编译成一份可以直接喂给大模型的确定性底稿，然后要么复制 Prompt 去网页版用，要么配个 API key 本地跑四章长文。

```bash
npm run studio     # 起在 127.0.0.1:4174（4173 被主站占用会自动顺延）
```

不配 `.env` 也能用：底稿编译、Prompt 生成、A4 打印、客户档案库都正常。只有「AI 分章精写」需要模型服务（OpenAI / DeepSeek / Gemini 兼容端点都行）。
